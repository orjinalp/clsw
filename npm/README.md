# @orjinalp/clsw

Claude Code profilleri (claude, claude2 … claude10) arasında hesap değiştirme; limit, açık oturum ve maliyet görüntüleme.

```sh
npm install -g @orjinalp/clsw
clsw list
```

Kurulumda platformun tek dosya programı GitHub Release'ten indirilir ve SHA-256 ile doğrulanır
(macOS arm64, Linux x64/arm64, Windows x64). Güncelleme: `npm install -g @orjinalp/clsw@latest`.

Diğer kurulum yolları ve ayrıntılar: https://github.com/orjinalp/clsw
